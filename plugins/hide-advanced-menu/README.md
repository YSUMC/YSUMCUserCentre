# 后台高级功能

保留 `hide-advanced-menu` 插件标识，将用户中心的高级功能入口移动到管理后台，在“高级功能 → OAuth2 应用”展示全站应用。插件配置按钮也打开同一页面。

- 列出所有用户和系统应用，包括已撤销的应用；支持搜索、状态筛选和分页。
- 展示 Client ID、应用名、所属用户、回调地址、客户端类型、状态及时间。
- 独立展示“创建操作人”。启用插件后，经 Passport 客户端模型创建的应用会记录登录用户的 UID、昵称快照、创建来源和记录时间；不会将应用所属用户冒充创建人。
- 历史应用及绕过应用模型的直接数据库写入没有可靠操作人，显示“历史未记录”。不推断或补造记录，也不记录密钥、令牌和密码。数据保存在独立的 `oauth_client_creations` 表，修改应用所属用户不会改写创建记录。
- 密钥不进入初始页面或列表查询结果。具有本模块“可管理”权限的用户可通过受 CSRF 保护的 POST 接口按需查看；“只读”权限无法读取。
- 密钥接口禁用缓存；页面隐藏或 60 秒后清除显示内容。哈希保存的密钥无法还原，不会作为原始密钥返回。
- 启用 YSUMC 后台权限功能时，本页自动出现在“插件配置 / 后台高级功能”权限列中；超级管理员始终可用。已有权限矩阵中的新模块默认不可访问，按需授权。未启用分级插件时沿用核心管理员限制。
- 不修改原来的用户 OAuth2 应用接口、客户端数据、授权状态或任何客户端密钥。

YSUMC 修订：`oauth-creator-audit-20261124`。保留上游版本号，部署时单独同步 `assets/` 到 `public/plugins/hide-advanced-menu/assets/`，避免触发线上插件版本变更的目录重建。
