## 运行时资源

当前部署使用固定的 Blessing Skin 6.0.2 发布资源。浏览器检查发现两个既有问题：预览组件把空披风、未选择的背景作为图片加载；源码形式的 Yggdrasil Connect 插件缺少编译后的浏览器脚本。

安装 Janus 开发依赖、解压固定版本发布资源并复制插件源码后，执行：

```sh
node deploy/prepare-runtime-assets.cjs
php artisan twig:clean
```

该脚本校验三份固定预览组件的替换位置，生成独立版本的资源和入口，保留上游原文件；同时编译插件的 `dnd.ts`、`config.ts`。上游资源版本或入口不匹配时立即报错，不能直接用于其他 BS 版本。

入口模板备份在 `.deploy/ui-runtime-backup/assets-app.twig`。如需撤销运行时修复，将它恢复到 `resources/views/assets/app.twig` 并清理 Twig 缓存。界面修改前的文件备份在 `.deploy/ui-backup-20261021/`。
